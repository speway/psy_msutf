# Website fonts

- Onest: https://github.com/google/fonts/tree/main/ofl/onest
- Lora: https://github.com/google/fonts/tree/main/ofl/lora

Downloaded from Google Fonts on 2026-09-06. License texts are included in each family directory.
Onest is a local variable WOFF2 subset. Lora is instantiated at weight 400 and subset for Latin, Cyrillic, punctuation and mathematical symbols, with the modified family renamed to **Sector Serif** in its font metadata and CSS, respecting the original reserved font name.
